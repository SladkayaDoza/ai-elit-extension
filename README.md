# AI ELIT Solver — Chrome Extension

## Встановлення

1. Відкрий `chrome://extensions/` у браузері.
2. Увімкни **Developer mode** (перемикач у правому верхньому куті).
3. Натисни **Load unpacked** → вибери папку з розширенням.
4. Натисни на іконку розширення → введи свій **OpenRouter API key**.
5. Вибери профіль: **Lite** (Sonnet 5.5) або **Pro** (Opus 5.5 / Fable 5.2).
6. Натисни **Save Settings**.

## Збірка для Chrome Web Store

Потрібен [Node.js](https://nodejs.org). Запусти `build.bat` (або `npm run build`):

- `ai-elit-extension/` — мініфікована збірка (можна завантажити через **Load unpacked**);
- `ai-elit-extension.zip` — архів для завантаження в Chrome Web Store.

Перед публікацією нової версії збільш `version` у `manifest.json`.

## Використання

На сторінці тесту з'явиться кнопка **✦ Answer with AI** поряд з "Перейти до наступного питання".  
Натисни її — розширення зчитає питання, надішле до AI, і автоматично поставить галочку на правильних відповідях.

Якщо кнопку приховано (перемикач у налаштуваннях), на сторінці нічого не з'являється: працює клавіша `\`, а результат видно на значку розширення (сірий «…» — думає, червоний «!» — помилка; після відповіді на питання з вибором — номери правильних варіантів, напр. «134», «0» — жоден не правильний) і в самому вікні розширення.

## Автозаповнення

У вікні розширення (вкладка **Main**):

- **Auto-fill answers** — вимкни, щоб нічого не вводилось автоматично: відповідь лише показується (номери на значку, повний текст у вікні розширення).
- **Also fill matching, dropdowns and text fields** — під-перемикач: вимкни, щоб автоматично відмічались лише radio та чекбокси, а відповіді на інші типи лише показувались.

## Підтримувані типи запитань

- `radio` — один правильний варіант
- `checkbox` — кілька правильних варіантів
- випадаючі списки / відповідність
- текстові поля
- питання з картинками (картинки надсилаються моделі)

## Моделі

| Модель | ID |
|--------|-----|
| Fable 5.2 | `anthropic/claude-fable-5.2` |
| Opus 5.5 | `anthropic/claude-opus-5.5` |
| Sonnet 5.5 | `anthropic/claude-sonnet-5.5` |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` |

Запасні моделі за замовчуванням (вкладка **Fallback**): Opus 5.5 → GPT-6.1 Sol → Gemini 3.8 Flash.
Якщо основна модель профілю повертає помилку, вони пробуються по черзі.

Якщо на OpenRouter закінчились кредити, розширення саме переходить на безкоштовні моделі:
Nemotron 3 Ultra 550B → Nemotron 3.5 Super VL → Gemma 4 31B (для питань з картинками — лише останні дві).
Через 15 хвилин знову пробуються платні моделі.

Будь-яку іншу модель OpenRouter можна додати на вкладці **Models**.

Отримати API key: https://openrouter.ai/keys

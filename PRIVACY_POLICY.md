# Политика конфиденциальности — AI ELIT Solver

**Дата вступления в силу:** 1 октября 2026 г.

Настоящая политика конфиденциальности описывает, какие данные собирает и обрабатывает расширение **AI ELIT Solver** для браузера Google Chrome, а также как эти данные используются, хранятся и защищаются.

---

## 1. Назначение расширения

AI ELIT Solver — это инструмент, помогающий студентам перепроверять свои ответы на тесты образовательной платформы ELIT (mix.sumdu.edu.ua, cabinet.sumdu.edu.ua) с помощью AI-моделей через сервис OpenRouter.

## 2. Какие данные собираются

### 2.1. Содержимое веб-страниц
Расширение извлекает со страниц тестов платформы ELIT следующие данные:
- Текст вопросов
- Варианты ответов (текст, структура)
- Изображения, относящиеся к вопросам (URL-адреса)

Эти данные используются **исключительно** для формирования запроса к AI-модели и получения ответа.

### 2.2. Пользовательские настройки
Расширение сохраняет в локальном хранилище браузера (`chrome.storage.local`):
- API-ключ OpenRouter, введённый пользователем
- Выбранные профили и модели AI
- Уровень рассуждения (reasoning level)
- Настройки отображения (скрытие кнопки, режим отладки)

### 2.3. Данные, которые НЕ собираются
Расширение **не собирает и не обрабатывает**:
- Персональные данные (имя, email, телефон, возраст)
- Учётные данные для входа на образовательную платформу (логин, пароль)
- Финансовые или платёжные данные
- Данные о местоположении
- Историю просмотров или поисковых запросов
- Данные об активности пользователя (клики, прокрутка, навигация)
- Файлы cookie

## 3. Как используются данные

| Данные | Цель использования |
|---|---|
| Текст вопросов и ответов | Отправляется в API OpenRouter для получения ответа AI-модели |
| API-ключ OpenRouter | Аутентификация запросов к API OpenRouter |
| Настройки профилей | Определение модели и параметров для каждого типа задачи |

Данные используются **исключительно** для основного назначения расширения и ни для каких иных целей.

## 4. Передача данных третьим сторонам

Расширение передаёт данные **только одному** стороннему сервису:

- **OpenRouter** (openrouter.ai) — текст вопросов и вариантов ответов отправляется через API для обработки AI-моделью. Обработка данных на стороне OpenRouter регулируется их [политикой конфиденциальности](https://openrouter.ai/privacy).

Данные **не передаются**:
- Серверам разработчика расширения (расширение не имеет собственного сервера)
- Рекламным или аналитическим сервисам
- Каким-либо иным третьим сторонам

Данные **не продаются** и **не используются** для профилирования, таргетинга или маркетинга.

## 5. Хранение данных

- Все пользовательские настройки хранятся **локально** на устройстве пользователя в `chrome.storage.local`.
- Расширение **не имеет** внешних серверов или баз данных.
- Расширение **не использует** cookies, трекеры, аналитику или системы мониторинга.
- Содержимое вопросов **не кэшируется** и **не сохраняется** после обработки запроса.

## 6. Безопасность

- API-ключ хранится в защищённом локальном хранилище браузера, доступном только данному расширению.
- Все запросы к API OpenRouter выполняются по протоколу HTTPS.
- Расширение не запрашивает и не обрабатывает учётные данные пользователей на образовательной платформе.
- Исходный код расширения полностью открыт и доступен для проверки.

## 7. Удалённый код

Расширение **не использует** удалённый код. Все скрипты (`content.js`, `popup.js`) входят в пакет расширения и выполняются локально. Взаимодействие с OpenRouter осуществляется исключительно через API-запросы за данными (ответы AI-модели), а не для загрузки исполняемого кода.

## 8. Права пользователя

Пользователь имеет право:
- **Удалить все данные** — достаточно удалить расширение из браузера или очистить его хранилище через настройки Chrome.
- **Контролировать данные** — пользователь самостоятельно решает, какой API-ключ использовать, какие модели выбрать, и когда запрашивать ответ AI.
- **Просмотреть исходный код** — код расширения полностью открыт на [GitHub](https://github.com/SladkayaDoza/ai-elit-extension).

## 9. Изменения политики

Мы оставляем за собой право обновлять данную политику конфиденциальности. Актуальная версия всегда доступна в данном файле в репозитории расширения. При существенных изменениях будет обновлена дата вступления в силу.

## 10. Контакты

По вопросам, связанным с конфиденциальностью и обработкой данных, вы можете обратиться через раздел [Issues](https://github.com/SladkayaDoza/ai-elit-extension/issues) в репозитории проекта.
